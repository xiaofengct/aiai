# xiaofeng 原创角色卡 · 30 张

这是一批**原创角色卡**，专门给这个 AI 聊天 App 用的。你把它们导入 App，就能分别和这 30 个不同的角色聊天。

- 全部由 **xiaofeng** 原创，**不包含任何已有作品（动漫 / 游戏 / 小说）里的角色**。
- **可自由分发、随意使用、也可以自己改**。
- 每张卡都附了一条**建议音色**（让 App 念这些角色的台词时，声音更贴合）。
- 风格覆盖很广：恋爱、学园、仙侠、科幻、悬疑、武侠、职场、历史、奇幻、治愈、搞笑、拟人、市井……总有一款对上你。

## 二、怎么导入（看图说话版）

1. 先把 `cards` 文件夹里的 `.json` 文件，复制到**手机能访问到的地方**（比如手机存储、微信文件传输助手、或直接连数据线拷进去）。
2. 打开 App，进入 **人设** 页面。
3. 点 **导入** 按钮。
4. 这时会弹出手机自带的**文件选择器**，找到你刚才放进去的 `.json` 文件（比如 `01-沈砚青.json`），选中它。
5. 导入成功后，人设列表里就会出现这个角色。点进去，就能开始聊天了。
6. 想导入下一个，重复第 3~5 步即可。**一次导入一个**，最稳妥。

> 如果点导入后没反应，多半是文件没放对位置、或选错了文件（要选 `.json` 结尾的）。

---

## 三、怎么配「建议音色」

1. 进入某个角色，打开**朗读 / 语音**相关的设置。
2. 在音色列表里，找上面表格里对应的那个（例如沈砚青选 `claire`）。
3. 选好后，让 App 念这个角色的台词，声音就会更贴合这个角色的性格。
